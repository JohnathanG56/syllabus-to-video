Turn a course outline into short 3Blue1Brown-style lessons.

  1. Topics. An LLM reads the syllabus and orders the teachable topics.
  2. Script and narration. Each topic becomes a 60–120 s script; Piper reads it aloud first.
  3. Animation. The LLM writes Manim code timed to the narration. It is checked, rendered in a locked-down sandbox, and repaired automatically if it fails.
  4. Assembly. Video, voice and captions are muxed with ffmpeg.
